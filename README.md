# AI Exam Prep Master (AI試験対策マスター)

An interactive, AI-powered web application designed to help students and professionals master certification exams such as the IT Passport and Generative AI Passport.

## 🚀 Overview

**AI Exam Prep Master** goes beyond traditional flashcard apps by leveraging the Gemini API to provide real-time, personalized tutoring. Instead of just showing correct answers, the app explains the logic behind each choice, helping users build a deep understanding of the subject matter.

## ✨ Key Features

- **Dynamic Question Generation:** Uses AI to generate questions based on the latest exam trends and specific categories (IT Passport, GenAI Passport, etc.).
- **Intelligent Explanations:** Provides immediate, detailed feedback. It explains why the correct answer is right and why the distractors are wrong.
- **Weakness Analysis:** Tracks user performance to identify areas that need more focus.
- **Modern UI/UX:** A clean, focused interface built with Tailwind CSS, featuring progress bars and score tracking to maintain motivation.
- **Customizable Learning:** Users can toggle between different exam types and difficulty levels.

## 🛠️ Tech Stack

- **Frontend:** React.js / Next.js
- **Styling:** Tailwind CSS
- **AI Engine:** Google Gemini API
- **State Management:** React Hooks

## 📖 How to Use

1. **Select Category:** Choose the exam you are studying for (e.g., IT Passport).
2. **Answer Questions:** Review the AI-generated question and select the best option.
3. **Learn from Feedback:** Read the detailed AI explanation to understand the "why" behind the answer.
4. **Track Progress:** Use the dashboard to monitor your score and see your improvement over time.

## 🎯 Target Audience

- Students preparing for Japanese national IT exams.
- Professionals looking to certify their knowledge in Generative AI.
- Anyone seeking a structured, interactive way to test their technical knowledge.
